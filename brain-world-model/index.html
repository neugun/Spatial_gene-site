04 · APPLICATIONS

Applications are treated as tests of what the representation is useful for.

应用不是装饰，而是检验表征究竟能做什么。

A

Brain-state decoding

脑状态解码

Can the standardized EEG representation recover sleep state in mouse and human recordings?

统一后的 EEG 表征能否在小鼠和人类数据中恢复睡眠状态？

B

Real optogenetic response prediction

真实光遗传干预响应预测

McBride et al. Neuropixels: predict post-stimulation cortical spikes from pre-state, then ask whether explicitly adding intervention identity improves held-out trials.

McBride 等的 Neuropixels 数据：先用干预前状态预测刺激后 cortical spikes，再检验显式加入 intervention identity 是否提高 held-out trial 预测。

C

Controlled causal world test

受控因果世界测试

A synthetic dynamical system with known interventions checks whether action information improves forecasting across horizons.

在具有已知干预 ground truth 的动力系统上，检验 action 信息能否在不同 horizon 提高预测。

D

Neural → behavior

神经活动 → 行为

OmniMouse neural activity predicts aligned treadmill and eye variables on held-out time windows.

用 OmniMouse 神经活动预测时间对齐的 treadmill 与 eye variables，并在 held-out 时间窗口评估。

05 · OBJECTIVE TEST

Which training objective helps which future?

不同训练目标到底帮助哪一种“未来”？

The same fixed evaluation masks compare baseline NEDS, a mixed brain+behavior world objective, and a future-neural predictive objective.

使用完全相同的固定 evaluation mask，对比 baseline NEDS、brain+behavior world objective 与 future-neural predictive objective。

06 · SCALE AUDIT

A nominal 1.5B model is not necessarily a 1.5B transferable model.

名义上的 1.5B，并不一定是真正 1.5B 的可迁移模型。

Linking all 423 BWB sessions reveals how strongly classic stitcher architectures inflate total parameters.

把完整 423 个 BWB session 接入后，可以直接看到经典 stitcher 架构如何膨胀总参数。

This is why the next scaling path is a token-native shared backbone: scale what transfers, not what memorizes session identity.
因此下一步扩展的是 token-native shared backbone：扩展真正可迁移的能力，而不是扩展 session identity 的记忆参数。
