# Claim/evidence ledger

This ledger makes the public evidence state explicit. It is not a model leaderboard.

**Status vocabulary**

- **PROMOTED:** used in the main biological interpretation.
- **SUPPORTIVE:** strengthens or explains a promoted claim but is not sufficient alone.
- **BOUNDARY:** a negative, mixed or abstraction-mismatched result that constrains the claim.
- **PENDING:** not promoted until a named validation gate is completed.

## How to update this ledger

Any promotion must cite a frozen result authority or canonical script and must preserve the corresponding negative/boundary result. Superseded model names may remain in provenance, but they should not define the biological claim.
