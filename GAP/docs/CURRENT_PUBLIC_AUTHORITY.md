## Current Q5 authority

Bugeon supplies a low-dimensional state-conditioned response-law result and a conservation gate. The nested molecular controller improves held-animal state-kernel prediction over a matched global controller, and the two highly conserved operator axes are the gene-readable axes.

Xu/PVH adds an independent susceptibility object across 11 conditions. Continuous molecular state predicts cross-state amplitude variability and total state range beyond hard type under held-mouse evaluation and an animal x hard-type correspondence shuffle. The promoted object is therefore **cross-state amplitude envelope/range**, not generic temporal complexity.

These results support a family of susceptibility coordinates. They do **not** imply that every Gamma-like quantity is already cross-animal predictable or that the missing context/receptor layer has been solved.

## Current Q6 authority

Transfer is judged by held-target biological units and target-label budget, not embedding similarity or parameter count. BrainBeacon, V2.2 and cross-system reference experts are useful only when they preserve an explicitly named functional object or reduce paired-label demand relative to a target-only baseline.

Strict zero-shot cross-species transfer is measurable but modest and axis-specific. Selected semantic axes survive matched permutation tests, while reverse directions can be null or negative. The current evidence therefore supports biologically aligned selective transfer and few-shot reuse, not a universal zero-shot neural foundation model.
