Three questions, one analysis contract

The public interface is organized by biological question, not model name. A result is promoted only when the functional target, molecular-evidence tier, held unit, matched comparator/null and metric all correspond to the stated claim.

Figure 1

Which functional coordinate is molecularly readable?

Variance, rank, classification, identity–response relation, AIC and effect size remain separate evidence axes. Low ΔR² does not imply no useful structure.

Figure 2

When can missing molecular state be recovered?

Reference qualification → endpoint lift → held-unit functional geometry. Atlas self-recovery is not functional proof.

Figure 3

What should a compact assay measure?

Fixed budget + matched-K random + true hidden-gene validation when available. Compression, replacement and prospective nomination are different claims.

Inference unit: animal / fish / worm / donor when available—not cell count. Boundary results remain public. A scientifically correct block or negative result is a tool PASS, not a reason to delete the dataset.

Molecular state parameterizes functional and structural response laws

The operator test compares the same X, same Y and same held-unit folds: independent Ridge versus shared full-rank or reduced-rank response laws. A positive R² delta alone is not sufficient; rank, AUROC/AUPRC, geometry and held-unit wins are retained.

Structural branch: molecular state strongly reads projection/connectivity coordinates in Chevee, C. elegans, MERGE-seq and Sorensen. Structural predictability does not imply that a shared operator must beat independent prediction.
