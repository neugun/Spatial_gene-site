# Restored Stage1-200 rules

1. Restore the old two-mode visual grammar: BLACK only for direct spatial/tissue panels; WHITE for analytical/nonspatial panels.
2. Never build a main composite before every source panel is independently publication-quality and manually inspectable.
3. One main figure = one biological question. Do not mix taxonomy, morphology, projection and reference validation merely because all are available.
4. Always show direct biological observation before derived statistics: tissue map/distribution first, effect size/model second.
5. Preserve S500/S530/S560 explicitly whenever section/AP structure matters; do not replace three-section biology with a single aggregate unless the aggregate is the actual claim.
6. Restore biologically readable names on figures. Method names (K5, CCA, MapMyCells thresholds, stages) belong in Methods/captions, not as the visual headline.
7. Keep primary, complementary, sensitivity and QC results visually and narratively separate.
8. Reference mapping must show actual labels/confidences/composition; binary support matrices may be supplementary audit only.
9. Morphology figures must show distributions and/or representative tissue examples, not only Cohen-d heatmaps.
10. Gene-level claims must be accompanied by actual spatial gene-expression panels for representative genes.
11. Use the frozen K5/R1-R5 framework as the correct early spatial comparator. Do not use deprecated SR0-SR3 to reject discrete-domain organization.
12. Before changing a frozen biological conclusion, perform a lineage-matched comparison against the exact previous authority and state why the old conclusion is superseded.
