# Spatial_gene - website

Static evidence website for the whole-brain spatially-restricted gene screen (Zhenggang Zhu, 2026): the gene report, 313 gene cards, per-gene figures, Allen ISH evidence images and result tables. Served at https://neugun.github.io/Spatial_gene-site/ . Code and methods: the private repository neugun/Spatial_gene.

Allen Mouse Brain Atlas ISH images are from the Allen Institute for Brain Science (https://mouse.brain-map.org) and remain under its terms of use.
